================================================================================
                            WHAT IS MODEL V7?
================================================================================

Model v7 is an OPTIMIZED version of model_v4 with three key Phase 1 improvements:

1. MORE AUGMENTATION (20 → 50 variants per image)
   - Increases training data from ~4,620 to ~11,550 samples
   - Better generalization, less overfitting
   - Expected benefit: +3-8% MAE improvement

2. BETTER DEPTH NORMALIZATION (fixed ÷255 → per-image min-max)
   - Normalizes depth by actual value range instead of fixed 255
   - Better feature learning from depth information
   - Expected benefit: +2-5% MAE improvement

3. SMARTER LEARNING RATES (fixed → warmup + cosine annealing)
   - Warmup (5 epochs): gradually increase LR to stabilize training
   - Cosine annealing: smoothly decrease LR to find better minima
   - Expected benefit: +5-10% MAE improvement

TOTAL EXPECTED: 0.6456 → ~0.55 MAE (+14-15%) ✓

================================================================================
                       TECHNICAL IMPROVEMENTS
================================================================================

IMPROVEMENT 1: INCREASED AUGMENTATION
  Why: Larger dataset reduces overfitting
  Implementation: num_aug_per_image = 50 (was 20)
  Effect: Creates ~11,550 training samples from 231 originals
  Expected MAE reduction: 3-8%

IMPROVEMENT 2: BETTER DEPTH NORMALIZATION
  Why: Different depth images have different value ranges
  Implementation: Per-image min-max normalization instead of fixed ÷255
  Effect: Learned features scale correctly regardless of depth range
  Expected MAE reduction: 2-5%

IMPROVEMENT 3: LEARNING RATE SCHEDULING
  Why: Fixed LR misses better convergence points
  Implementation: 
    - Warmup: LinearLR(10% → 100%) for 5 epochs
    - Annealing: CosineAnnealingLR for remaining epochs
  Effect: Gradual convergence to better local minima
  Expected MAE reduction: 5-10%
