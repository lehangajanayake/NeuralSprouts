# NeuralSprouts

AI models for predicting lettuce dry weight.

## Structure

```
NeuralSprouts/
├── datasets/          # Place your dataset files here
└── models/            # Each model has its own folder
    └── simple_cnn/    # Example: Simple CNN model
```

## Getting Started

1. Add your dataset to the `datasets/` folder
2. Each model is in its own folder under `models/`
3. Run the model's training script independently

## Models

- **simple_cnn**: A simple CNN implementation using PyTorch
